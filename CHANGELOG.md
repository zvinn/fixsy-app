# 📝 Fixsy Changelog

All notable changes to the Fixsy project are documented in this file.

## [1.2.0] - 2026-09-11

### 🚀 Performance & Architecture
- **Vite 7 & React 18 Engine:** Full migration to Vite 7 bundler with lightning-fast Hot Module Replacement (<50ms).
- **TypeScript 5 Strict Typing:** 100% type-checked interfaces for services, hooks, and role authentication.
- **Production Build Optimization:** Chunk splitting with dedicated bundles for Firebase, Leaflet maps, Recharts, and UI utilities.
- **Vercel Cloud Deployment:** Pre-configured with \ercel.json\ supporting client-side single page app routing and edge caching.

### 🎨 UI & UX Modernization
- **Centered Nav Pill:** Replaced blurry CSS shadow with high-definition Material 3 rounded icon pill and top indicator bar.
- **Glassmorphic Job Market:** Added modern glassmorphism cards with smooth Framer Motion list stagger animations.
- **Role Selection Dialog:** Guaranteed instant dismissal on backdrops, escape key, and cross button, preventing interface lockup.
- **Egyptian Market Demo Data:** Preloaded realistic Cairo, Giza, and Alexandria technician jobs and maintenance requests.

## [1.1.0] - 2026-09-08
- Integrated Groq AI & Google Gemini fault diagnostics in Egyptian colloquial dialect.
- Real-time weather geolocation alerts powered by Open-Meteo API.
- PWA offline caching with Workbox and custom app manifest.

## [1.0.0] - 2026-09-01
- Initial public release with client, technician, and admin role isolation.
